# Portfolio – ฟอร์มบันทึกซื้อ/ขาย สำหรับ Google Sheet "Portfolio"

Apps Script ที่ใส่ในไฟล์ Portfolio เดิม เพื่อให้ไม่ต้องไปกรอกในชีต **Transaction** เองทุกครั้งที่ซื้อ
**ไม่ได้เปลี่ยนโครงสร้างชีตเดิม** สคริปต์เขียนแถวลง Transaction แบบเดียวกับที่กรอกเองอยู่แล้ว
ชีต Cost / Portfolio Summary จึงทำงานต่อได้ตามเดิม

## ปัญหาของวิธีเดิม

| ตอนนี้ต้องทำเอง | หลังติดตั้ง |
|---|---|
| ไปที่แถวสุดท้ายของ Transaction แล้วลากสูตร H:P ลงมา | สคริปต์ copy สูตรจากแถวก่อนหน้าให้เอง |
| หุ้น/ETF ที่ซื้อเป็น USD ต้องพิมพ์สูตร `=ราคาUSD*อัตราแลกเปลี่ยน` เอง | กรอกยอดเงิน (บาท) + จำนวนหน่วย ราคาต่อหน่วยคำนวณให้ ส่วนอัตราแลกเปลี่ยนดึงจาก Price |
| DCA ทุกเดือน (VOO, BTC, SCBGOLDHRMF, SCBTB) ต้องกรอกทีละแถว | แท็บ DCA: ยอดเงินกรอกไว้ให้แล้ว ใส่แค่จำนวนหน่วย กดบันทึกครั้งเดียว |
| ใช้ Google Sheets บนมือถือกรอกยาก | เปิดเป็นเว็บแอปบนมือถือได้ (ฟอร์มเดียวกัน) |
| กรอกผิดแล้วไม่รู้ตัว (ดูหัวข้อ "ข้อมูลที่น่าจะผิด" ด้านล่าง) | เตือนก่อนบันทึกถ้าวันที่อยู่ในอนาคต ราคาต่างจากราคาตลาดเกิน 30% ขายเกินจำนวนที่ถือ หรือบันทึกรายการเดิมซ้ำ |
| ต้องคัดลอกค่าลง Monthly Summary เอง | มีเมนู Snapshot และตั้งให้ทำอัตโนมัติทุกเดือนได้ |

## เมนู `📈 Portfolio` ที่จะเพิ่มเข้ามา

- **➕ บันทึกซื้อ / ขาย**: เปิดแถบข้างพร้อมฟอร์ม
  - เลือกสินทรัพย์จากรายการ (เรียงตามรายการ DCA และสินทรัพย์ที่ซื้อบ่อยก่อน)
  - แสดงจำนวนที่ถืออยู่ ต้นทุนเฉลี่ย ราคาที่ซื้อครั้งล่าสุด และราคาวันนี้
  - กรอก **ยอดเงิน + จำนวนหน่วย** (ตามใบยืนยันของ SCB Easy / InnovestX) แล้วจะคำนวณราคาต่อหน่วยให้
    หรือจะกรอกราคาต่อหน่วยแล้วให้คำนวณยอดเงินแทนก็ได้
  - ดูตัวอย่างผลก่อนบันทึก: จำนวนหน่วยและต้นทุนเฉลี่ยหลังซื้อ หรือกำไรที่รับรู้เมื่อขาย
  - รองรับ ซื้อ / ขาย / ปันผล
- **📅 บันทึก DCA**: แสดงทุกแถวที่ติด `dca` ในคอลัมน์ G ของ Portfolio Summary โดยใช้ยอดเงินจากคอลัมน์ F
  ถ้าเดือนไหนไม่ได้ซื้อตัวไหนก็ติ๊กออก
- **📸 Snapshot ลง Monthly Summary ตอนนี้**: เพิ่มคอลัมน์ใหม่ใน Monthly Summary โดยใช้ค่าจาก Portfolio Summary
  (จับคู่ตามชื่อแถว) ถ้าเซลล์ไหนเป็น error จะแจ้งก่อนบันทึก
- **⏰ ตั้ง Snapshot อัตโนมัติทุกเดือน**: ทำ snapshot ทุกวันที่ 20 เวลาประมาณ 20:00 น. (แก้ได้ที่ `PF.SNAPSHOT_DAY`)
  ถ้าเดือนนั้นมี snapshot อยู่แล้วจะข้ามไป
- **🔍 ตรวจข้อมูล Transaction**: ตรวจหาแถวที่วันที่อยู่ในอนาคต แถวที่สูตรคำนวณไม่ได้
  และแถวที่ราคาต่างจากรายการก่อน/หลังของสินทรัพย์เดียวกันมาก

## วิธีติดตั้ง (ประมาณ 5 นาที)

1. เปิดไฟล์ Portfolio แล้วไปที่ **Extensions → Apps Script** (เป็นโปรเจกต์เดียวกับที่มี `setMutualfundInfo` อยู่)
2. กด **+ → Script** สร้างไฟล์ชื่อ `Portfolio` แล้ววางเนื้อหาจาก [`apps-script/Portfolio.gs`](apps-script/Portfolio.gs)
3. กด **+ → Script** สร้างไฟล์ชื่อ `Menu` แล้ววางเนื้อหาจาก [`apps-script/Menu.gs`](apps-script/Menu.gs)
   - ถ้าในโปรเจกต์มีฟังก์ชัน `onOpen` หรือ `doGet` อยู่แล้ว ไม่ต้องสร้างไฟล์นี้
     ให้เพิ่ม `pfOnOpen(e);` ใน `onOpen` เดิม และ `return pfDoGet(e);` ใน `doGet` เดิมแทน
4. กด **+ → HTML** สร้างไฟล์ชื่อ `QuickAdd` (ต้องใช้ชื่อนี้) แล้ววางเนื้อหาจาก [`apps-script/QuickAdd.html`](apps-script/QuickAdd.html)
5. กด Save แล้ว refresh หน้า Google Sheet จะมีเมนู **📈 Portfolio** ขึ้นมา
   ครั้งแรกที่ใช้ Google จะขอสิทธิ์ ให้กด Allow

### ใช้บนมือถือ (ไม่บังคับ)

1. ใน Apps Script กด **Deploy → New deployment → Web app**
2. ตั้ง *Execute as* = **Me** และ *Who has access* = **Only myself**
3. นำ URL ที่ได้ไปเพิ่มลงหน้าจอโฮมของมือถือ (ถ้าเติม `?tab=dca` ท้าย URL จะเปิดที่แท็บ DCA เลย)

ต้องเปิดเมนูในชีตอย่างน้อยหนึ่งครั้งก่อน เพื่อให้สคริปต์จำได้ว่าต้องเขียนลงไฟล์ไหน

## ข้อจำกัด

- สินทรัพย์ใหม่ที่ยังไม่เคยซื้อ ฟอร์มบันทึกลง Transaction ได้ แต่ยังต้องเพิ่มแถวในชีต Price / Cost / Portfolio Summary เอง
  (ฟอร์มจะเตือน) เพราะตอนนี้แต่ละแถวในสองชีตนั้นอ้างอิงตำแหน่งแถวตรง ๆ
- ยอด DCA ของ BTC ใน Portfolio Summary เป็นยอดต่อเดือน (35,000) แต่ซื้อจริงทุกสัปดาห์ ให้แก้ยอดเงินในฟอร์มก่อนบันทึก
  (ถ้าลืม ระบบจะเตือนว่าราคาต่างจากราคาตลาด)
